# Safey QMS — Software Specification Document

**Version:** 1.0  
**Date:** 10 July 2026  
**Status:** Production

---

## 1. Overview

Safey QMS is a browser-based Quality Management System for small-scale manufacturing. It provides full forward and backward traceability from raw material vendor to finished product, with automated wastage tracking, stock management, production planning, and batch recall.

### 1.1 Goals

- Track every raw material batch from purchase through production to finished product
- Enforce stock invariants via database triggers (no negative stock, auto-deductions)
- Surface low-stock and high-wastage alerts automatically
- Enable full batch recall with one-click quarantine cascade
- Run entirely in-browser with a PostgreSQL backend (Supabase)

### 1.2 Target Users

Small manufacturing factories producing finished goods from raw materials through intermediate parts. Operators, production managers, and quality managers.

```
Vendors ──1:N──> Raw Materials ──1:N──> Part Batches ──N:1──> Parts
                                                      │
                                          Production Batch Parts
                                                      │
                                              Production Batches ──N:1──> Products

                                                                       BOM ──N:1──> Parts

Wastage Logs (polymorphic: part / product level)
Alerts (auto-generated by triggers)

```

## 4. Database Functions (RPCs)

### `get_dashboard_kpis() → JSONB`

Single round-trip returning all dashboard KPIs:

- Total raw material stock (kg), active raw batch count, material type count
- Finished goods count, active product count
- Today's production: batch count, units, total actual kg, total wastage
- Vendor count
- Parts in stock, low-stock part count
- Low-stock raw batch count
- Unread alert count
- Today's wastage kg and percentage

### `get_part_availability(part_ids UUID[]) → JSONB`

Given an array of part IDs, returns:

- Per-part: total available quantity
- Per-batch: batch_id, batch_number, original quantity, remaining quantity, created_at

Used by the production wizard and planning page.

### `get_traceability_forward(raw_material_id UUID) → JSONB`

Given a raw material batch ID:

- Raw material details + vendor info
- All downstream part_batches with their production_batches (product, quantity, date, status)

### `get_traceability_backward(production_batch_id UUID) → JSONB`

Given a production batch ID:

- Production batch + product info
- All upstream part_batches with raw_materials and vendors

### `next_number_for_prefix(prefix, table, column) → INTEGER`

Utility using advisory lock + MAX query for sequential batch numbering.

## 5. Database Triggers

### 5.1 Auto-Timestamps

`set_updated_at()` fires BEFORE UPDATE on: `vendors`, `raw_materials`, `parts`, `app_settings`, `other_items`. Sets `updated_at = now()`.

### 5.2 Batch Number Generation

BEFORE INSERT triggers auto-generate sequential batch numbers:

| Table                | Pattern               | Example             |
| -------------------- | --------------------- | ------------------- |
| `raw_materials`      | `{MATERIAL_TYPE}-NNN` | `PP-001`            |
| `part_batches`       | `{PART_CODE}-BNNN`    | `CLIP-B003`         |
| `production_batches` | `BNNN`                | `B027`              |
| `production_plans`   | `PLAN-YYYYMMDD-NNN`   | `PLAN-20260710-001` |

### 5.3 Part Batch After Insert

When a part batch is created:

1. Deduct `actual_usage_kg` from `raw_materials.remaining_quantity_kg`
2. Add `quantity` to `parts.current_stock`
3. Insert a `wastage_logs` entry
4. If wastage % > threshold → insert `high_wastage_part` alert
5. If RM remaining < 50 kg → insert `low_stock_raw` alert

### 5.4 Production Batch Part After Insert

When a production batch part is consumed:

- Deduct `quantity_used` from `parts.current_stock`
- Raise exception if stock goes negative (prevents over-consumption)

### 5.5 Production Batch After Insert

When a production batch is created:

1. If `extra_raw_material_batch_id` set → deduct from that RM
2. Insert product-level `wastage_logs` entry
3. If wastage > threshold → insert `high_wastage_product` alert

### 5.6 Other Items Low Stock

When an other item is inserted/updated:

- If `current_stock < low_stock_threshold` → insert `low_stock_raw` alert

### 5.7 Raw Material Block Cascade

When `is_blocked` changes from false to true on `raw_materials`:

1. Block all related `part_batches`
2. Set `status='recalled'` on all related `production_batches`
3. Insert a critical alert with affected counts

## 6. Features (Page by Page)

### 6.1 Dashboard (`/`)

KPI cards with real-time data from `get_dashboard_kpis` RPC:

- Raw Material Stock (kg) + batch count + material types
- Finished Goods count + active products
- Today's Production (batches, units)
- Vendors count
- Parts in Stock + low-stock count
- Raw Batches + running-low count
- Unread Alerts
- Today's Wastage (kg, %)

Quick actions: "Trace batch", "Start production". Each card links to its detail page.

### 6.2 Vendors (`/vendors`)

- Searchable table of all vendors (name, phone, address, materials supplied)
- Add/Edit/Delete vendors (delete guarded by FK check)
- Toggle active/inactive
- Multi-tag material type input
- View dialog showing recent batches

### 6.3 Raw Materials (`/raw-materials`)

- Filterable table (by material type, vendor, show blocked)
- Subtitle shows total stock kg and inventory value
- Add new raw material → auto-generates batch number via trigger
- Block/Unblock batches (block cascades via trigger)
- View dialog with tabs: Usage, Trace Forward, Wastage summary
- Vendor names resolved client-side via vendorMap

### 6.4 Parts (`/parts`)

- Table of part definitions with expandable rows showing production batches
- Add/Edit parts (name, material type, consumption per unit kg, threshold)
- "Produce" button opens 4-step PartProduceDialog wizard:
  1. Quantity
  2. Pick raw material batch (FIFO auto-allocate option)
  3. Actual usage + wastage reason
  4. Confirm
- Stock vs threshold with color-coded progress bars

### 6.5 Products (`/products`)

- Card grid of product catalog
- Add/Edit product (name, code, description)
- Toggle active/inactive
- Link to BOM editor
- Shows parts count per product

### 6.6 Bill of Materials (`/products-bom/$id`)

- Split-pane editor: available parts (left) / current BOM (right)
- Add parts with quantity_required per unit
- Remove parts from BOM
- Saves by replacing all BOM rows

### 6.7 Production (`/production`)

- Table of last 20 production batches
- Shows: batch number, product, quantity, expected/actual kg, wastage %, date, status
- Links to planning and new production

### 6.8 Production Wizard (`/production-new`)

5-step guided production flow:

1. **Product & Quantity** — select product, enter quantity to produce
2. **Availability Check** — calls `get_part_availability` RPC, shows part shortages
3. **Pick Part Batches** — manual selection or FIFO auto-allocate
4. **Date & Notes** — production date, optional notes
5. **Confirm & Submit** — calls `commit_production` RPC

### 6.9 Production Planning (`/production-planning`)

- Select product + quantity + date
- Computes BOM requirements
- Checks part availability via `get_part_availability` RPC
- Computes raw material shortfalls
- Shows parts + RM requirement tables
- Save plan to `production_plans` table

### 6.10 Stock (`/stock`)

- Unified view combining raw materials, parts, products, and other items
- Filterable by type (All / Raw / Part / Product / Other)
- Searchable by name or code
- Type badges, low-stock warnings
- Links to stock history pages

### 6.11 Stock History (`/stock-history/$type/$id`)

Parametric route for detailed stock history:

- **Raw**: part batches produced from this RM, usage, wastage
- **Part**: batch history, source RM, vendor
- **Product**: BOM + all production runs

### 6.12 Other Items (`/other-items`)

- CRUD for miscellaneous inventory (packaging, consumables, tools)
- Category, unit, current stock, low-stock threshold
- Auto-alerts when stock drops below threshold

### 6.13 Alerts (`/alerts`)

- Tabbed: All, Unread, Low Stock, High Wastage, Shortage
- Mark single or all as read
- Clicking an alert navigates to the relevant page
- Sidebar badge shows unread count (polled every 60s)

### 6.14 Reports (`/reports`)

Three report tabs:

1. **Wastage** — date range picker, bar/pie charts, CSV export
2. **Monthly Production** — month picker, chart by product/day, CSV export
3. **Stock Report** — raw/parts/finished goods tables, CSV export

### 6.15 Traceability (`/traceability`)

- Search any batch number across raw/part/production tables
- Select a result to see the full trace tree
- **Backward trace**: production → parts → raw material → vendor
- **Forward trace**: raw material → vendor + part batches → production batches
- Calls `get_traceability_forward` and `get_traceability_backward` RPCs
- Wastage summary per trace

### 6.16 Batch Recall (`/batch-recall`)

- Select a raw material batch
- Trace affected part batches + production batches
- "Mark All Affected as Recalled" → sets `is_blocked=true` (cascades via trigger)
- Type "RECALL" to confirm
- Shows recall history
- Export affected list as CSV

### 6.17 Settings (`/settings`)

- Factory name
- Currency symbol
- Wastage alert threshold (%)
- Low stock raw threshold (kg)
- Stored in `app_settings` singleton row

## 7. Business Rules

### 7.1 Stock Invariants (Enforced by Triggers)

| Rule                                                     | Enforcement                                  |
| -------------------------------------------------------- | -------------------------------------------- |
| Part production deducts from RM remaining                | `part_batch_after_insert` trigger            |
| Part production adds to parts current_stock              | `part_batch_after_insert` trigger            |
| Production consumption deducts from parts current_stock  | `production_batch_part_after_insert` trigger |
| No negative parts stock                                  | Exception raised in trigger                  |
| Wastage auto-logged at part and product level            | Triggers insert into `wastage_logs`          |
| Blocking RM cascades to part batches + production recall | `raw_material_block_cascade` trigger         |

### 7.2 Batch Number Format

| Entity           | Format                | Example             |
| ---------------- | --------------------- | ------------------- |
| Raw Material     | `{MATERIAL_TYPE}-NNN` | `PP-001`            |
| Part Batch       | `{PART_CODE}-BNNN`    | `CLIP-B003`         |
| Production Batch | `BNNN`                | `B027`              |
| Production Plan  | `PLAN-YYYYMMDD-NNN`   | `PLAN-20260710-001` |

### 7.3 Alert Types

| Type                   | Trigger Condition             | Severity |
| ---------------------- | ----------------------------- | -------- |
| `low_stock_raw`        | RM remaining < threshold      | warning  |
| `low_stock_part`       | Part stock < threshold        | warning  |
| `high_wastage_part`    | Part wastage % > threshold    | critical |
| `high_wastage_product` | Product wastage % > threshold | critical |
| `shortage_planned`     | Production plan has shortages | warning  |

## 9. Data Flow

```
Purchase RM ──> Raw Material batch (auto batch#)
                    │
Produce Part ──> Part Batch (auto batch#)
                    │  ├── deducts from RM remaining
                    │  ├── adds to Part stock
                    │  ├── logs wastage
                    │  └── fires alerts
                    │
Produce Product ──> Production Batch (auto batch#)
                    │  ├── deducts from Part stock (per BOM)
                    │  ├── logs wastage
                    │  └── fires alerts
                    │
Block/Recall ──> Cascades through RM → Part Batches → Production Batches
```

## 11. Non-Functional Requirements

- **Performance**: Dashboard KPIs via single RPC call; debounced search inputs; lazy-loaded charts
- **Data Integrity**: All stock mutations enforced by database triggers; no client-side stock management
- **Offline**: Connection lost banner with auto-retry
- **Audit**: Console-based audit logging on all create/update/delete/block actions
- **Responsive**: Mobile sidebar via sheet component; responsive table layouts
